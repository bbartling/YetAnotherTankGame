# Main Menu (Blender Source)

Blender scene matching Unity MenuManager home screen.

## Open

`BlenderSource/MainMenu/YetAnotherTankMainMenu.blend`

View through **MenuCamera**.

## Tank prop

Uses existing game model **SillyPlayerTank** appended from:

`BlenderSource/Tanks/SillyPlayerTank.blend`

Do not rebuild a new tank mesh for this scene.

## Cartoon Army Soldier

Sketchfab UID `5b1d988defe044988dca5890a787eb29`.
Enable Sketchfab in BlenderMCP, download, export to `models/CartoonArmySoldier.glb`, then replace the placeholder soldier.

## Unity buttons

- DRIVE -> TankDrivingPractice
- CANNON -> TankTargetPractice
- WAR -> Practice war mode
